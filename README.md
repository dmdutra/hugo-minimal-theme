# Dutra Theme

A minimal Hugo theme inspired by the personal blog of Gabriel M. Dutra.

## Features
- Light and dark mode based on `prefers-color-scheme`.
- Fast, clean, and JS-free.
- Custom pages for `projects` and `resume`.

## Installation

Inside the folder of your Hugo site run:

```bash
git submodule add https://github.com/your-username/dutra-theme.git themes/dutra-theme
```

In your `hugo.toml`:

```toml
theme = "dutra-theme"
```

## Setup

Take a look at the `exampleSite` folder for an example on how to configure your content and data files.
